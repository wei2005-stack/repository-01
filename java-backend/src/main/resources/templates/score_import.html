导入说明
文件格式要求：
  1. 文件必须为 CSV 格式
  2. 第一行为表头，必须包含以下列：
    • 学号 - 必填
    • 课程编号 - 必填
    • 成绩 - 必填，0-100
    • 学期 - 必填，如 2024-2025-1
    • 考试类型 - 选填，默认"期末"
  3. 学号和课程编号必须在系统中存在
  4. 相同学号+课程+学期+考试类型不能重复
