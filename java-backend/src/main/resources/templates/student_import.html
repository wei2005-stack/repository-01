导入说明
文件格式要求：
  1. 文件必须为 CSV 格式
  2. 第一行为表头，必须包含以下列：
    • 学号 - 必填，不可重复
    • 姓名 - 必填
    • 性别 - 必填，男/女
    • 出生日期 - 选填，格式YYYY-MM-DD
    • 身份证号 - 选填，不可重复
    • 联系电话 - 选填
    • 家庭住址 - 选填
    • 入学时间 - 必填，格式YYYY-MM-DD
    • 班级编号 - 必填，必须在系统中存在
  3. 学号和身份证号不能与已有数据重复
  4. 班级编号必须在系统中存在
